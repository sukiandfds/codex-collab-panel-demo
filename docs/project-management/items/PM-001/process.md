# PM-001：独立项目管理系统过程记录

本文件只记录项目管理系统这条功能自身的弯路、决策和效率问题。移动端通用适配、服务重启、跨设备实时状态等可复用问题不在这里复制，按链接读取 `PROC-*` 或对应功能记录。

### 2026-08-02 | PM-001-P01 | detour | P1 | resolved

- 条目：PM-001
- 用户可见现象：项目进度入口曾被做成单独的 HTML 原型，不能作为长期可维护的项目管理系统使用。
- 用户原话：`我要的不是 html，而是一个真正好用的项目进度管理系统，每个部分应该拆分好，便于维护更新。`
- 助手初步理解：用户要求的是可维护的真实功能和独立数据目录，不是把内容静态铺在一个页面里。
- 错误路径：先做页面展示，再回头补数据组织和维护边界。
- 影响：移动端入口和后续更新方式不清晰，造成返工和沟通成本。
- 正确路径/决策：先建立 `docs/project-management/` 数据源、条目目录和字段规范，再由读取器和 React 功能模块消费；不把旧功能档案混入新目录。
- 防再犯触发器：需求出现“真正系统”“方便维护”“不要和原文件混在一起”时，先检查数据源、文件归属和维护入口，再改页面。
- 归属判断：条目专属；目录边界规则同时受 `PROC-001` 约束。
- 证据：`docs/project-management/PROJECT.md`、`SCHEMA.md`、`docs/feature-development/PROJECT_PROGRESS_DEVELOPMENT_PLAN_2026-08-02.md`。
- 关联：`PROC-001`、`updates.md`。

### 2026-08-02 | PM-001-P02 | decision | P1 | mitigated

- 条目：PM-001
- 用户可见现象：页面一度把所有条目的完整内容都展示出来，信息拥挤，用户无法快速判断今天要做什么。
- 用户原话：`现在所有东西都展示出来了，太乱了，没有按照我刚才说的只展示摘要等基本内容。`
- 助手初步理解：列表只呈现摘要、级别、状态和更新时间；具体内容、预计效果和过程记录应在详情或日志层按需读取。
- 错误路径：把列表、详情和日志当成同一展示层，一次加载全部 Markdown 内容。
- 影响：首屏阅读负担增加，移动端切换和详情定位变慢，字段重复维护风险变高。
- 正确路径/决策：`INDEX.md` 只定位，`item.md` 提供当前快照，`updates.md` 提供历史，`process.md` 只做过程复盘；前端摘要优先、详情懒加载。
- 防再犯触发器：新增字段或页面区块时，先判断它属于摘要、当前详情还是历史日志，禁止把三层内容直接合并到列表。
- 归属判断：条目专属；“摘要与详情分层”可迁移到其他管理页时，再登记通用规则。
- 证据：`docs/project-management/README.md`、`SCHEMA.md`、`web-ui/src/features/project-management/`。
- 关联：`updates.md`。

### 2026-08-02 | PM-001-P03 | efficiency | P1 | mitigated

- 条目：PM-001
- 用户可见现象：项目管理页切换速度明显慢于 Codex 对话页，用户等待页面而不是等待数据。
- 用户原话：`我对现在项目管理页面的加载速度非常不满意。我的目标是至少要做到现在 codex 页面，切换对话的速度。`
- 助手初步理解：需要先找出用户实际等待的环节，再用最小改动让摘要先出现，不能直接重写后端架构。
- 错误路径：一开始把延迟归因于 Markdown 读取，忽略整页导航、网络优先缓存和空白加载态。
- 影响：重复检查和无效优化消耗时间，用户感知到的是页面卡顿。
- 正确路径/决策：分别测量 API、会话列表和导航；接口约 95ms、会话列表约 162ms 时，优先使用导航缓存优先、后台更新和 `sessionStorage` 摘要缓存，让旧摘要先显示再静默更新。
- 防再犯触发器：用户描述“页面慢”时，先拆分导航、接口、解析和渲染四段计时；没有测量前不引入数据库或后台索引服务。
- 归属判断：条目专属优化；“先测量再改性能”关联 `PROC-006`、`PROC-010`。
- 证据：`docs/feature-development/DEVELOPMENT_EXPERIENCE_2026-08-02.md#EXP-004`、`web-ui/public/sw.js`、`web-ui/src/features/project-management/data/projectManagementApi.ts`。
- 关联：`PROC-006`、`PROC-010`、`updates.md`。
