## 简短摘要

提供项目群聊、多个 Agent 参与和可见的讨论过程。

## 具体内容

使用场景：用户与多个 Agent 在同一个项目群中讨论、分工和追踪结果。

当前体验：已有真实群聊、四个 Agent、讨论模式、@、附件和增量回复；协作任务分工和持续状态还需统一。

交互变化：先与单人 Codex 对齐消息、过程、断线恢复、停止、追加和失败反馈，再扩展 Agent 间协作。

## 预计效果

用户可以看懂谁在工作、当前讨论到哪一步，并能在群聊中插入或停止工作，不会因为群聊形式掩盖基础能力问题。
