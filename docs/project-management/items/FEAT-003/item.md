# 附件与对话内容渲染

## 用户原话

历史功能文档未保存原始用户原话，待补录；不能根据文件内容倒推原话。

## 助手初步理解

该部分原始对话上下文未被独立保存，初步理解待补录。

## 简短摘要

支持图片、音频、视频和普通文件在对话中的上传与展示。

## 具体内容

使用场景：用户在单人对话或群聊中发送附件并查看结果。

当前体验：已有图片、音频、视频和普通文件展示，上传链路仍是 Demo 级。

交互变化：补齐上传、预览、下载、失败提示、重试和多端草稿保持。

## 预计效果

用户能明确知道附件是否上传成功、是否可以预览或下载；切换页面或网络异常时不会无提示丢失附件。
