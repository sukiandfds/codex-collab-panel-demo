# FEAT-017 多业务项目与 Codex 会话归类

当前产品定义更新时间：2026-08-17 11:10 +08:00

## 当前产品定义：会话所有者与工作目标分离

- 普通项目会话归对应业务项目。
- 员工直属单聊和员工参与项目群聊的长期会话始终归员工自己的项目。
- 项目群聊属于工作项目，完整公共群聊记录保存在工作项目中；员工公开发布的群消息可以进入该记录。
- 员工项目群聊会话可以绑定目标工作项目及其路径，并对授权范围内文件进行读取、创建、修改或删除，但这不改变会话所有者。
- 员工 Thread 不得出现在目标工作项目的普通会话列表中。所有者项目、目标工作项目和实际文件访问路径必须分别记录，不能只根据 `cwd` 推断产品归属。
- 详细群聊调用和上下文规则以 `FEAT-002-group-multi-agent.md` 为准。

## 本次范围

- 在项目目录中显示多个本机 Codex 业务项目。
- 按 Codex Thread 的工作目录归类已有会话。
- 允许打开并继续已登记业务项目中的原有 Thread。

## 当前实现

- 主项目继续使用 `negus`。
- 其他业务项目从本机 `runtime/business-projects.json` 读取，不提交用户绝对路径。
- 默认列表只显示未归档会话。
- 点击业务项目后，新建会话使用该项目路径；项目增删界面不在本次范围。
