# 公网附件上传延迟记录

## 用户场景

用户通过手机或电脑网页端发送带图片的消息，点击发送后长时间没有发出；纯文字消息正常。网页端查看已有图片速度正常，桌面 Codex 发送图片后网页端也能较快看到。

用户反馈：单张图片发送时需要等待较长时间；两张图片同时发送时等待可能接近一分钟。这里的“两张接近一分钟”是用户体验记录，尚未作为精确基准重复测量。

## 验证过程

1. 选取同一张约 120 KB 的图片，在本机地址和固定公网地址分别调用同一个附件上传接口。
2. 保持请求内容、文件、文件名和 Content-Type 一致，只改变访问地址。
3. 记录请求从发出到收到完整 HTTP 响应的耗时，并检查响应状态码。
4. 另行读取已经保存的图片，比较公网读取是否同样延迟。
5. 对照前后端发送链路，确认图片上传完成前是否会提交正式消息。

## 验证结果

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| 本机上传 | 约 0.09-0.10 秒 | `http://127.0.0.1:9360`，同一张图片 |
| 公网上传首次测试 | 约 10 秒 | `https://codex.negus.us.ci` |
| 公网上传复测 | 约 16.25 秒 | 同一公网入口、同一图片 |
| 公网响应 | HTTP `201` | 请求最终到达 Negus 并完成保存 |
| 公网读取已有图片 | 正常 | 未复现同等程度的读取延迟 |

## 请求链路

当前网页发送附件的顺序是：

```text
浏览器
  -> POST /api/uploads
  -> Cloudflare Named Tunnel
  -> http://127.0.0.1:9360
  -> Negus media service 读取请求体并保存文件
  -> 返回 Media ID
  -> 浏览器再提交 /api/session/message
```

因此，上传请求完成前，正式消息不会提交给 Codex。用户看到的“消息没有发出去”，首先是公网附件上传阶段在等待，不是 Codex 已经收到消息但回复慢。

本地服务保存逻辑包含读取请求体、计算 SHA-256、写入 `runtime/uploads` 和登记 Media；同一文件在本机约 0.1 秒完成，不能解释公网额外增加的 10-16 秒等待。

## 已确认事实

- 本机 `http://127.0.0.1:9360` 上传同一张约 120 KB 图片：约 0.09-0.10 秒。
- 公网 `https://codex.negus.us.ci` 上传同一张图片：首次约 10 秒，复测约 16.25 秒。
- 公网入口返回 `201`，说明请求最终能够到达 Negus；问题表现为公网上传链路出现明显等待，而不是本机保存失败。
- 读取已有图片的公网链路正常。
- 当前 Cloudflare Named Tunnel 的 origin 是 `http://127.0.0.1:9360`；当前配置没有显式指定 `quic` 或 `http2`。
- 当前请求响应命中的 Cloudflare colo 标识为 `LHR`。这只能作为线路证据，不能单独证明唯一根因。

## 用户影响

网页端带图片消息无法像纯文字一样立即发送，用户可能等待十几秒后关闭页面；VPN 可能改善速度，但 VPN 本身不稳定，不能作为长期依赖。

## 当前判断

问题边界已从 Negus 本机图片处理收缩到公网 Tunnel/大陆网络的上传方向。现有证据支持“公网上传路径延迟”这一定位，但还不能把延迟唯一归因于 Cloudflare Tunnel、某个具体 colo、QUIC/HTTP2 协议或某个运营商线路。

目前可以排除或暂不支持的判断：

- 不是图片生成 API 的生成耗时；本问题发生在普通附件上传、正式消息提交之前。
- 不是本机磁盘写入或图片登记耗时；本机同接口耗时约 0.1 秒。
- 不是公网图片读取普遍变慢；已有图片读取正常。
- 不能仅凭 HTTP `201` 判断体验正常；它只说明请求最终成功。

## 尚未验证

- Cloudflare Tunnel 强制使用 `http2` 与 `quic` 的对照耗时。
- 不同网络、设备和时间段的重复样本。
- Cloudflare R2、腾讯 COS、阿里 OSS 或区域中转节点的直传耗时。
- 断点续传、对象存储直传是否能与当前 Codex 本地文件路径合同兼容。

## 后续方向

后续方案评估应优先比较“浏览器直传对象存储，再由 Negus 获取文件”和“稳定区域中转节点”两类架构；Tunnel `http2/quic` 切换只能作为低成本对照实验，不能预先视为根治方案。任何线路切换前先确认没有活动 Turn、附件上传或其他不可中断任务。
