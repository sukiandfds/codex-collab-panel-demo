## 归属规则

- 一个文件只有一个主归属领域。
- `features/<feature>/` 负责功能内的 UI、状态、接口和类型；跨功能稳定能力放到 `shared/`。
- 服务端路由只负责请求解析和分发；业务状态、持久化和 Codex 协议分别留在服务/存储/适配层。
- 启动、重启、环境检查、远程入口属于运行时与平台，不混入业务服务。
- 普通文件不逐个登记；只有入口、边界、公共基础设施、超长文件和跨域例外需要记录。
- 文件超过约 250 行，或同时承担两个以上职责时，进入拆分候选，不代表立即移动或重写。

## 变更时如何维护

只有以下情况才更新本目录：新增领域、文件主归属改变、模块拆分、公共依赖方向改变、跨域例外增加或消除。普通功能迭代只更新对应功能文档，不要求维护一张总文件表。
