# 开发记录与历史资料目录

本目录保存开发日志、验证记录、事故复盘和项目历史资料。原来位于根目录的 `DEVELOPMENT_LOG_*`、`DEVELOPMENT_BUG_LOG_*`、`DEVELOPMENT_PROCESS_BLOCKERS_*` 和 `VISION_NOTES.md` 已移入本目录，保留原文件名作为历史证据。

命名：

- `<主题>_DEVLOG_YYYY-MM-DD.md`
- `<主题>_VERIFICATION_YYYY-MM-DD.md`
- `<主题>_INCIDENT_YYYY-MM-DD.md`

记录应包含范围、对应任务编号、产品 commit、实际修改、检查结果、用户可见变化和未解决问题。当前状态仍回写到对应项目管理条目。
